# Tri Nguyen  React Portfolio

## Description
This project is a responsive React-based portfolio website showcasing Tri Nguyens professional background, skills, awards, and career timeline. It demonstrates React fundamentals, component-based architecture, responsive design, and interactive UI features. The portfolio includes a dynamic navigation bar with mobile dropdown support, a profile section with awards and skill scroll, and a timeline of education and career milestones.

---

## Technologies Used
1. **React.js** for component-based UI development
2. **React Router** for navigation between pages
3. **CSS Grid & Flexbox** for responsive layouts
4. **Custom CSS variables** for theme management (light/dark mode with accent colors)
5. **Font Awesome** for icons
6. **Animations & transitions** (CSS keyframes, hover effects, continuous marquee)
7. **JavaScript (ES6+)** for JSX and component logic

---

## Usage
The portfolio provides:
- A **responsive header** with navigation links and theme toggle
- A **mobile dropdown menu** with hamburger toggle
- A **profile section** with profile picture and awards row
- A **skill marquee** that scrolls continuously, restricted to awards width
- An **education and career timeline** with logos and roles
- Theme-aware headings that adapt accent colors (blue in light mode, purple in dark mode)
- A fully responsive design across desktop, tablet, and mobile

---

## How To Use
1. Clone or download the repository,
2. Install dependencies:
   ```bash
   "run npm install" and "npm run dev",
3. Open the app in your browser (default: http://localhost:5173/ if using Vite),
4. - Navigate through the portfolio:
   - Use the header navigation links (desktop/tablet),
   - On mobile, open the dropdown menu via the hamburger icon,
   - Explore the profile, awards, skill scroll, and timeline sections.
5. Toggle between light and dark themes to see accent color changes.
